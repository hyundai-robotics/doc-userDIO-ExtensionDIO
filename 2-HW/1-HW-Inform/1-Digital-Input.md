# 2.1.1. 数字输入

下面的图表显示了数字输入端子排的引脚配置。<br>
每个端子排可接收16个输入信号，可根据用途选择NPN或PNP类型的输入。<br>
当额外安装BD682时，可增加16pt数字输入。<br>

![](../../_assets/27.사용자DIO_보드_커넥터_DIN.png)<br>
<图1. 用户DIO（BD681）数字输入连接器>

{% hint style="info" %}
1号脚与10号脚，11号脚与20号脚在电路板内部相连。
{% endhint %}
