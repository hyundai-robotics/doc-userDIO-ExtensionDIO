# 2.1. 硬件信息

用户DIO (BD681) 通过数字I/O端口允许与各种设备的集成和配置。<br>
扩展DIO (BD682) 还允许额外的数字I/O端口和与传送带信号的同步。<br>
电路板的基本硬件配置如下。<br>

{% hint style="warning" %}
使用两个BD681电路板时，请确保安装位置和开关ON/OFF设置正确。
为了防止电路板损坏，必须将一个BD681电路板安装在原始BD671插槽中。
{% endhint %}
