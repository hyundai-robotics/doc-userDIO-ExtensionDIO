# 2.1. 硬件信息

用户 DIO (BD681) 通过数字 I/O 端口允许与各种设备的集成和配置。<br>
扩展 DIO (BD682) 还允许额外的数字 I/O 端口和与输送机信号的同步。<br>
板的基本硬件配置如下。<br>

{% hint style="warning" %}
使用两个 BD681 板时，请确保安装位置和开关 ON/OFF 设置正确。
为防止板损坏，必须将一个 BD681 板安装在原 BD671 插槽中。
{% endhint %}
